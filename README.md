# Basic HTML Resume

This repository contains a simple resume created using basic HTML tags.

## Technologies Used

- HTML5

## HTML Tags Used

- <h1> to <h6>
- <p>
- <br>
- <hr>
- <b>
- <strong>
- <i>
- <small>
- <sub>
- <sup>

## Sections Included

- Name
- Career Objective
- Education
- Skills
- Projects
- Contact Details

## Project Structure

```
basic-html-resume/
│
├── index.html
└── README.md
```

## Output
