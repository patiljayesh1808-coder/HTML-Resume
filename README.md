# Basic HTML Resume

## Description

This project contains a simple resume created using basic HTML tags. The purpose of this project is to understand the structure of an HTML document and the use of commonly used tags.

---

## Technologies Used

- HTML5

---

## HTML Tags Used

- `<h1>` to `<h6>`
- `<p>`
- `<br>`
- `<hr>`
- `<b>`
- `<strong>`
- `<i>`
- `<small>`
- `<sub>`
- `<sup>`

---

## Sections Included

- Personal Information
- Career Objective
- Education
- Skills
- Projects
- Contact Details
